# My Personal Portfolio Website

A responsive personal portfolio website built and deployed as part of my Web Development Internship at **Codomax Digital**.

## 🌐 Live Demo
- **Live Website:** [https://pavithra2008am-blip.github.io/My-portfolio/](https://pavithra2008am-blip.github.io/My-portfolio/)

## ✨ Features
- **Hero & About Me:** Personal introduction with a one-click downloadable resume (`Pavithra_AM_Professional_Resume.pdf`)
- **Education & Skills:** Academic background (B.E. Computer Science and Engineering, Chennai Institute of Technology) and core technical skills (HTML, CSS, JavaScript, Java, Python)
- **Contact Section:** Interactive message form along with direct clickable links for Email, LinkedIn, and GitHub
- **Theme Support:** Dark/Light mode toggle for comfortable viewing

## 🛠️ Technologies Used
- **Frontend:** HTML5, CSS3, JavaScript
- **Hosting:** GitHub Pages
